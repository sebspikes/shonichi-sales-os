# Shonichi Sales OS

The shared sales machine for Shonichi, operated by both founders through Claude Code.

- **What it does:** finds qualified STR operators, generates each one a free Property Pulse report, and turns the golden-hour deep work sessions into 25 quality outreach touches per founder per week, tracked on a shared scoreboard.
- **How to use it:** open a Claude Code session pointed at this repo and type `run my session`. That is the whole interface. See `CLAUDE.md` for the other commands.
- **Where things live:** strategy and schemas in `core/` (locked, both founders must agree to changes), the September build plan in `build/`, message engine in `messages/`, session logs in `logs/`, leaderboard in `scoreboard/`, scripts in `tools/`. Lead data lives in Airtable, not here.
- **The pact:** 25 quality touches each, every week. The scoreboard keeps us honest. Loser of the week buys the coffee.
